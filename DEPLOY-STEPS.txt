===============================================================================
                        BACKTEST 部署步驟 (簡化版)
===============================================================================

前置檢查
-------
□ 已修復 workerd: rm -rf node_modules && npm install
□ Cloudflare 登入: wrangler login
□ 在 ~/cowork/develop/backtest 目錄

===============================================================================
步驟 1: 建立 D1 資料庫 (2分鐘)
===============================================================================

執行命令:
  npm run db:create

預期輸出:
  ✓ Database created successfully!
  ✓ Database ID: abc123def456...

⚠️  複製 database_id，下一步需要


===============================================================================
步驟 2: 更新 wrangler.jsonc (1分鐘)
===============================================================================

編輯文件: wrangler.jsonc

找到這段:
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "backtest-portfolios",
      "database_id": "5b9e9e1a-9e9e-4e1a-9e9e-9e9e9e9e9e9e"
    }
  ]

將 "database_id" 的值替換為步驟 1 得到的 ID

例如:
  "database_id": "abc123def456..."

保存文件


===============================================================================
步驟 3: 執行 Migration (1分鐘)
===============================================================================

執行命令:
  npm run db:migrate

預期輸出:
  ✓ Executed 0001_create_portfolios.sql


===============================================================================
步驟 4: 部署到 Cloudflare (2分鐘)
===============================================================================

執行命令:
  npm run deploy

預期輸出:
  ✓ Uploaded worker successfully
  ✓ Deployed to https://etf-backtest-platform.clare8628.workers.dev


===============================================================================
步驟 5: 驗證部署 (2分鐘)
===============================================================================

方法 A: 測試 API
  執行: curl https://etf-backtest-platform.clare8628.workers.dev/api/portfolios
  預期: {"groups":[]}

方法 B: 在瀏覽器中測試
  1. 打開: https://etf-backtest-platform.clare8628.workers.dev
  2. 新增比較組 (例如: QQQ, VOO)
  3. 執行回測 (點擊 "Run Backtest")
  4. 等待結果出現
  5. 關閉瀏覽器，再用新標籤頁打開同網址
  6. ✅ 驗證: 組合應該還在 (數據從 D1 同步)

方法 C: 查看實時日誌
  執行: wrangler tail

===============================================================================
常見問題
===============================================================================

Q: 部署後無法訪問?
A: 等待 1-2 分鐘讓 Worker 完全上線，然後重新整理

Q: API 回傳 502 或 timeout?
A: 檢查 database_id 是否正確，執行: wrangler d1 list

Q: 組合未同步到新瀏覽器?
A: 檢查瀏覽器 Console，可能是 API 失敗，查看 wrangler tail

Q: 如何查看資料庫?
A: wrangler d1 execute backtest-portfolios --command "SELECT * FROM portfolios;"
