Q: "workerd on another platform"
A: rm -rf node_modules && npm install

Q: "D1 binding not found"
A: 檢查 wrangler.jsonc 的 database_id，確認不是預設值

Q: "TypeScript error"
A: npm 執行 npx tsc --noEmit 檢查錯誤

Q: 部署成功但無法訪問
A: 等待 1-2 分鐘讓 Worker 完全上線

Q: API 回傳 502
A: 檢查 D1 binding，執行 wrangler d1 list 驗證
