================================================================================
                              常見問題
================================================================================

Q: "command not found: wrangler"
A: 需要全局安裝 wrangler
   npm install -g wrangler

Q: "D1 database_id 未配置"
A: 需要先建立 D1 資料庫
   npm run db:create
   然後複製 ID 到 wrangler.jsonc

Q: 部署失敗
A: 查看錯誤訊息，通常是：
   - Cloudflare 未登入：wrangler login
   - TypeScript 錯誤：npx tsc --noEmit
   - node_modules 損壞：rm -rf node_modules && npm install
